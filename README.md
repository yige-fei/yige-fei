**Local AI · Data Engineering · Financial Analytics**

I build practical tools for working with code, documents, and financial data. My work sits at the intersection of **local-first AI**, **reproducible data workflows**, and **evidence-led analysis**.

## 🔍 How I approach projects

- **Evidence before claims.** Keep sources, assumptions, and limitations visible.
- **Reproducibility by design.** Document setup, tests, and known constraints.
- **AI with clear boundaries.** Use scoped tools, explicit permissions, and independent checks where possible.

**Exploring next:** Reusable, read-only Model Context Protocol (MCP) tools for code intelligence. *Exploration, not a shipped feature.*
